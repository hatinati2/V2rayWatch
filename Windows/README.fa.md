# V2rayWatch برای Windows

**نسخه دسکتاپ: 0.2.3 — Windows x64**

این نسخه یک کلاینت دسکتاپ برای ویندوز است که بر پایهٔ پروژهٔ متن‌باز v2rayN نسخهٔ 7.25.6 ساخته شده و با نام و نشان V2rayWatch بسته‌بندی شده است. این موضوع در مجوز و اعلان‌های حقوقی هم شفاف ذکر شده؛ برنامه یک پیاده‌سازی مستقل از موتور v2rayN نیست.

## زبان فارسی و انگلیسی

برنامه منابع ترجمهٔ فارسی و انگلیسی را دارد. در نصب تازه، اگر زبان رابط ویندوز فارسی باشد، فارسی انتخاب می‌شود؛ در غیر این صورت انگلیسی پیش‌فرض است. شناسهٔ برنامه در شروع Windows به‌صورت مستقل تنظیم می‌شود تا Taskbar آن را از v2rayN جدا گروه‌بندی کند. اگر میان‌بر قدیمی v2rayN را قبلاً Pin کرده‌ای، آن را Unpin کن و پس از اجرای V2rayWatch.exe جدید، خود V2rayWatch را Pin کن. دکمهٔ تغییر زبان در داشبورد تنظیم را ذخیره می‌کند و برنامه را خودکار با زبان جدید دوباره اجرا می‌کند.

## امکانات اصلی

- واردکردن کانفیگ تکی، چندتایی و Subscription
- اسکن QR از صفحه یا تصویر و واردکردن لینک از Clipboard
- پروتکل‌ها و هسته‌های پشتیبانی‌شده توسط Xray و sing-box
- پشتیبانی از XHTTP از طریق Xray Core و Hysteria2 از طریق sing-box
- مدیریت سرورها، تست دستی Real Delay برای همهٔ پروفایل‌ها (با Core آزمایشی مستقل برای هر لینک، بدون نیاز به System Proxy/TUN) و انتخاب سرور فعال
- System Proxy ویندوز
- TUN mode برای مسیریابی ترافیک سیستم (به مجوز Administrator و درایور Wintun همراه بسته نیاز دارد)
- قوانین مسیریابی، DNS و تنظیمات پیشرفته‌ای که در پروژهٔ upstream موجود است
- اجرا در System Tray

پشتیبانی دقیق هر نوع کانفیگ به هستهٔ انتخاب‌شده و فیلدهای داخل لینک بستگی دارد؛ کانفیگ‌های خصوصی یا پارامترهای اختصاصی ممکن است نیازمند بررسی باشند.

## تفاوت تست لینک با اتصال ویندوز

دکمهٔ «تست واقعی همه لینک‌ها» هر پروفایل را جداگانه از مسیر Core آزمایشی خودش بررسی می‌کند و تنظیمات ترافیک ویندوز را تغییر نمی‌دهد. برای استفادهٔ واقعی از یک پروفایل، آن را فعال کن و سپس System Proxy یا TUN را جداگانه روشن کن.

**پایش دوره‌ای و تاریخچهٔ Uptime در Windows 0.2.3:** در شاخهٔ توسعه، دکمهٔ «شروع پایش» همهٔ پروفایل‌های قابل‌تست را با Real Ping واقعی موتور v2rayN بررسی می‌کند. فاصلهٔ پایش به‌صورت عددی و دلخواه از ۱ تا ۹۹۹۹۹ ثانیه وارد می‌شود؛ اعداد فارسی، عربی و لاتین پذیرفته می‌شوند. آستانهٔ ۱ تا ۳ شکست متوالی قابل انتخاب است و مقدار پیش‌فرض ۲۰ ثانیه و ۲ شکست است. دکمهٔ حذف پروفایل انتخاب‌شده از فرمان حذف اصلی v2rayN استفاده می‌کند و پیش از حذف تأیید می‌گیرد. وضعیت Connected / Unstable / Disconnected / Not testable در جدول نمایش داده می‌شود و زیر هر لینک نوار ۲۰ خانه‌ایِ نتایج اخیر قرار دارد: سبز برای پاسخ موفق، قرمز برای آزمون ناموفق و خاکستری برای نتیجهٔ ثبت‌نشده/غیرقابل‌تست. تاریخچه در فایل محلی ذخیره می‌شود و پس از بستن و اجرای دوبارهٔ برنامه باقی می‌ماند. ترتیب نوار از قدیمی به جدید (چپ به راست) است. هنگام قطع یا بازیابی نیز اعلان System Tray فرستاده می‌شود. نتایج تست دستی وارد محاسبهٔ پایش نمی‌شوند و اضافه‌شدن پروفایل وسط یک دور باعث هشدار کاذب نمی‌شود.

پایش سلامت مستقل از System Proxy و TUN است. تا وقتی برنامه در حال اجرا باشد (حتی در System Tray) کار می‌کند؛ با خروج کامل از برنامه متوقف می‌شود و بعد از اجرای مجدد باید دوباره شروع شود. اگر یک دور به علت timeout طول بکشد، دور بعدی روی آن انباشته نمی‌شود و فاصلهٔ واقعی ممکن است بیشتر از ۲۰ ثانیه شود. نسخهٔ Windows 0.2.3 توسط مالک پروژه روی دستگاه واقعی Windows آزمایش و تأیید شده است. پایش در حالی که برنامه در System Tray باز است ادامه دارد؛ بعد از خروج کامل باید دوباره شروع شود. جزئیات فنی در [ANDROID_WINDOWS_PARITY.fa.md](ANDROID_WINDOWS_PARITY.fa.md) آمده است.

## نصب و اجرا

1. فایل V2rayWatch-Windows-x64.zip را از صفحهٔ Releases دریافت کن.
2. ZIP را در یک پوشهٔ دلخواه استخراج کن.
3. فایل V2rayWatch.exe را اجرا کن.
4. برای حالت پراکسی معمولی، از منوی برنامه System Proxy را فعال کن.
5. برای TUN mode، برنامه را با Run as administrator اجرا کن و TUN را فعال کن.

این بسته Portable است و نصب‌کنندهٔ جداگانه ندارد.

## نکتهٔ مهم دربارهٔ این نسخه

این یک build آزمایشی Windows x64 بر پایهٔ v2rayN 7.25.6 است. روی runner ویندوز کامپایل شده، اما پیش از انتشار پایدار باید روی Windows 10/11 واقعی، با System Proxy و TUN و چند کانفیگ واقعی آزمایش شود. امضای کد Authenticode ندارد؛ بنابراین Windows SmartScreen ممکن است دربارهٔ ناشر ناشناس هشدار بدهد.
