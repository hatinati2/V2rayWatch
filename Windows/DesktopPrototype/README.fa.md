# پیش‌نمایش رابط دسکتاپ V2rayWatch

این پروژه، اولین پوستهٔ قابل‌ساخت WPF برای تبدیل طرح داشبورد به برنامهٔ ویندوز است.

## اجرا
نیازمند Windows و .NET 10 SDK است:

```powershell
dotnet build .\V2rayWatch.DesktopPrototype.csproj -c Release
dotnet run --project .\V2rayWatch.DesktopPrototype.csproj
```

## محدوده فعلی
- داشبورد تیره با هویت بصری V2rayWatch
- چیدمان RTL فارسی و تغییر جهت کلی به LTR
- ناوبری اولیه بین بخش‌ها
- وضعیت قطع اتصال و مقادیر خالی به‌جای آمار ساختگی

## محدودیت مهم
این پروژه فعلاً نمونهٔ رابط کاربری است و به موتور v2rayN/Xray/sing-box وصل نیست. کنترل اتصال، System Proxy، TUN، فهرست سرورها و نمودار تا زمان اتصال به سرویس واقعی عمداً غیرفعال‌اند. این پروژه نباید به‌عنوان کلاینت VPN آماده استفاده یا جایگزین بستهٔ فعلی Release معرفی شود.
