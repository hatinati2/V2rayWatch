## V2rayWatch 0.1.0

### Windows
- Portable Windows x64 desktop client based on v2rayN 7.25.6.
- Persian and English UI resources.
- Includes the upstream Xray and sing-box core bundle.
- Includes System Proxy, TUN, routing, profile/subscription import, QR import, and core features supported by the upstream project.
- The modified GPL-3.0 source archive is attached.

### Android preview
- Includes the V2rayWatch 0.2.1 debug preview APK.
- Android is currently a monitoring app for real outbound delay, not a full Android VPN client.

### Before using
- The Windows build is unsigned and experimental.
- Run TUN mode as Administrator.
- Test on your own Windows device and verify your profiles before relying on it.
