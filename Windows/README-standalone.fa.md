# V2rayWatch Windows — ابزار مستقل تست و پایش لینک

این شاخه نسخهٔ مستقل Windows از V2rayWatch را می‌سازد. هدف برنامه مدیریت VPN یا عبور ترافیک کل ویندوز نیست؛ هدفش واردکردن کانفیگ‌ها و بررسی واقعی هر لینک به‌صورت مستقل است. برنامه از چارچوب UI، تنظیمات، ViewModelها و منطق کلاینت v2rayN استفاده نمی‌کند.

## امکانات این پیش‌نمایش

- افزودن یک لینک، چند لینک، لینک از Clipboard، فایل متنی و Xray JSON
- افزودن Subscription با دکمهٔ واقعی «دریافت و افزودن لینک‌ها»؛ دریافت فقط از HTTPS
- استخراج پاسخ متنی یا Base64 اشتراک و افزودن پروفایل‌ها به جدول
- ذخیرهٔ آدرس Subscription و به‌روزرسانی جداگانه یا همهٔ اشتراک‌ها
- حفظ پروفایل‌های دستی هنگام به‌روزرسانی اشتراک؛ پروفایل‌های متعلق به همان منبع با پاسخ جدید همگام می‌شوند
- تست یک پروفایل یا همهٔ پروفایل‌ها با Xray Core موقت و درخواست HTTPS از مسیر outbound همان پروفایل
- پایش زمان‌بندی‌شده، فاصلهٔ قابل تنظیم ۱ تا ۹۹۹۹ ثانیه، آستانهٔ ۱ تا ۹۹۹۹ شکست متوالی و timeout قابل تنظیم
- وضعیت هر لینک، تأخیر آخر، زمان آخرین بررسی و نوار تاریخچهٔ ۲۰ تست خودکار
- تاریخچهٔ بلندمدت برای هر پروفایل با نمای ۲۴ ساعت و ۷ روز، درصد بررسی‌های موفق، تعداد شکست‌ها، میانگین/بازهٔ تأخیر و نمودار زمانی
- تاریخچه فقط هنگام پایش دستیِ فعال ثبت می‌شود؛ تست‌های دستی و زمان‌هایی که پایش متوقف است وارد آمار نمی‌شوند. زمان بدون بررسی «بدون داده» است، نه قطعی
- نگهداری محلی ۷ روز اخیر در پایگاه SQLite مستقل از فایل Backup مشترک؛ داده‌های قدیمی‌تر خودکار پاک می‌شوند
- اعلان سینی هنگام قطع و بازیابی لینک، با کنترل مستقل هرکدام
- پشتیبان رمزگذاری‌شدهٔ قابل‌انتقال با همان فرمت Android؛ فایل `.v2vwbackup` را با همان عبارت عبور در گوشی یا ویندوز بازیابی کن
- بازیابی غیرمخرب: پروفایل‌های فعلی حفظ و لینک‌های تکراری رد می‌شوند؛ تنظیمات پایش، اعلان‌ها و تاریخچهٔ Uptime منتقل می‌شوند
- نمایش QR برای لینک پروفایل انتخاب‌شده، ذخیرهٔ تصویر PNG و واردکردن لینک با خواندن QR از فایل تصویر
- رابط فارسی/انگلیسی
- ذخیرهٔ داده‌های پروفایل و Subscription در مسیر LocalAppData با DPAPI ویندوز

## منطق تست

برای هر پروفایل یک فرایند موقت xray.exe با JSON همان لینک اجرا می‌شود. برنامه فقط یک ورودی SOCKS روی 127.0.0.1 برای همان تست ایجاد می‌کند؛ هیچ System Proxy، VPN/TUN یا تنظیم شبکهٔ ویندوز را تغییر نمی‌دهد. سپس به URL آزمایشی HTTPS از داخل همان SOCKS درخواست می‌فرستد و پاسخ HTTP 200 یا 204 را موفق می‌داند. اگر URL اصلی شکست بخورد، URL جایگزین بررسی می‌شود. Core بعد از تست متوقف و فایل موقت پاک می‌شود.

این روش تست پورت یا TCP ping نیست؛ اتصال خروجی تا مقصد HTTPS را از مسیر outbound همان کانفیگ بررسی می‌کند. نتیجه به قابل‌دسترسی‌بودن URLهای تست و پشتیبانی Xray از قابلیت‌های آن پروفایل نیز وابسته است.

## Subscription

دکمهٔ افزودن اشتراک محتوا را واقعاً از URL دریافت می‌کند؛ فقط HTTPS، حداکثر ۲ MiB، حداکثر ۵ redirect امن و timeout محدود مجاز است. اگر پاسخ قابل‌پردازش نباشد، هیچ پروفایلی اضافه نمی‌شود و خطا نمایش داده می‌شود.

هنگام Update:
- پاسخ اشتراک ابتدا کامل دریافت و parse می‌شود.
- موارد تکراری نادیده گرفته می‌شوند.
- موارد جدید متعلق به همان Subscription ثبت می‌شوند.
- پروفایل‌های قبلی که در پاسخ جدید نیستند حذف نمی‌شوند؛ کاربر می‌تواند آن‌ها را جداگانه حذف کند.
- پروفایل‌هایی که دستی یا از منبع دیگری وارد شده‌اند نیز حفظ می‌شوند.

## محدودیت‌های این مرحله

- موتور تست این مرحله باینری رسمی Xray Core از مخزن XTLS/Xray-core است؛ پشتیبانی پروتکل/transport دقیقاً به نسخهٔ Xray همراه بسته وابسته است. پشتیبانی sing-box در این نسخه پیاده‌سازی نشده است.
- برخی پروفایل‌های کامل Xray JSON یا transportهای پیشرفته ممکن است نیازمند اصلاح باشند.
- پایش فقط با فشردن دستی دکمهٔ «شروع پایش» فعال می‌شود. پس از اجرای دوبارهٔ برنامه یا راه‌اندازی مجدد ویندوز، پایش خودکار شروع نمی‌شود؛ کاربر هر بار خودش آن را فعال می‌کند. پایش در حالی اجرا می‌شود که برنامه باز است (از جمله System Tray) و با خروج کامل متوقف می‌شود.
- زمان یک دور پایش با توجه به تعداد پروفایل‌ها و timeout می‌تواند از فاصلهٔ انتخاب‌شده بیشتر شود؛ دورها روی هم اجرا نمی‌شوند.
- آدرس‌های Subscription و تنظیمات اختصاصی ویندوز در فایل پشتیبان مشترک نیستند؛ فقط پروفایل‌ها و تنظیمات پایش/اعلان منتقل می‌شوند.
- تاریخچهٔ بلندمدت ویندوز محلی است و در Backup مشترک Android/Windows منتقل نمی‌شود.
- اسکن QR از فایل تصویر پشتیبانی می‌شود؛ اسکن زنده با وب‌کم هنوز اضافه نشده است.
- این پیش‌نمایش هنوز به نصب و آزمایش واقعی روی Windows 10/11 نیاز دارد. موفقیت CI جای تست زندهٔ اتصال چند کانفیگ را نمی‌گیرد.

## اجرا از سورس

نیازمند Windows و .NET 10 SDK:

    dotnet build Windows/DesktopPrototype/V2rayWatch.DesktopPrototype.csproj -c Release
    dotnet run --project Windows/DesktopPrototype/V2rayWatch.DesktopPrototype.csproj

برای تست parser و ساختار JSON خروجی:

    dotnet run --project Windows/DesktopPrototype.Tests/V2rayWatch.DesktopPrototype.Tests.csproj -c Release

نسخهٔ Portable تولیدشده توسط GitHub Actions شامل V2rayWatch.exe و core/xray.exe است. Xray Core نسخهٔ رسمی v26.10.31 از مخزن XTLS دریافت می‌شود و SHA-256 آرشیو Windows x64 در CI با مقدار رسمی ثبت‌شده برای همان Release مقایسه می‌شود. مجوز Xray و اعلان‌های ثالث باید همراه بسته نگه داشته شوند.
