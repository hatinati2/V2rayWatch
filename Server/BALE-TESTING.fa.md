# آزمایش اعلان بله در V2rayWatch

این قابلیت فعلاً آزمایشی است و روی شاخهٔ `feature/bale-notifications-test` قرار دارد. **نسخهٔ پایدار و سرویس فعلی V2rayWatch تغییر نمی‌کنند.** نصب‌کنندهٔ آزمایشی یک نمونهٔ دوم و مستقل با سرویس، پورت، تنظیمات، دیتابیس و کلید رمزنگاری جدا می‌سازد.

## پیش‌نیاز

- نصب قبلی V2rayWatch Linux Server روی Ubuntu 24.04 یا 26.04
- وجود .NET 10 SDK در مسیر `/opt/dotnet` (نصب‌کنندهٔ پایدار آن را نصب می‌کند)
- ربات ساخته‌شده در پیام‌رسان بله

این تست فقط ارسال اعلان مستقیم به API بله را آزمایش می‌کند؛ ارتباطی با Telegram ندارد.

**محدودیت احتمالی API:** مستندات بله می‌گوید API معمولی بازو محدودیت نرخ تعاملی دارد. برای اعلان به کاربری که قبلاً ربات را Start کرده اما ارسال خارج از گفت‌وگوی فعال، API کسب‌وکاری بله با سهمیهٔ جداگانه و کسر اعتبار هر پیام معرفی شده است. این شاخه فعلاً API معمولی را آزمایش می‌کند؛ اگر پیام آزمایشی برسد ولی اعلان‌های بعدی در خارج از بازهٔ تعامل فعال رد شوند، باید دسترسی و هزینهٔ API کسب‌وکاری بررسی شود. 

## ۱. ساخت ربات بله

1. در پیام‌رسان بله وارد گفت‌وگو با `@botfather` شو.
2. یک ربات جدید بساز و توکن آن را دریافت کن.
3. وارد گفت‌وگوی خصوصی ربات جدید شو و پیام `/start` را بفرست.
4. تا پایان تنظیمات، webhook یا مصرف‌کنندهٔ دیگری برای `getUpdates` این ربات تنظیم نکن.

توکن ربات را در چت عمومی، تیکت یا مخزن Git قرار نده.

## ۲. نصب نمونهٔ آزمایشی کنار نسخهٔ پایدار

روی همان Ubuntu که نسخهٔ پایدار V2rayWatch نصب است، دستور زیر را اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/hatinati2/V2rayWatch/feature/bale-notifications-test/Server/scripts/install-bale-test.sh | sudo bash
```

نصب‌کننده از شاخهٔ آزمایشی سورس را می‌گیرد و با .NET 10 می‌سازد. سپس نمونهٔ تست را با مشخصات زیر نصب می‌کند:

| مورد | مقدار |
|---|---|
| سرویس اصلی | `v2raywatch` (بدون تغییر) |
| سرویس آزمایشی | `v2raywatch-bale-test` |
| پورت پنل تست | `6101` |
| مسیر برنامه تست | `/opt/v2raywatch-bale-test` |
| تنظیمات تست | `/etc/v2raywatch-bale-test` |
| دیتابیس تست | `/var/lib/v2raywatch-bale-test` |

در پایان، آدرس پنل آزمایشی، نام کاربری `admin` و رمز مستقل نمایش داده می‌شود. رمز در فایل زیر هم با مجوز `0600` ذخیره می‌شود:

`/root/v2raywatch-bale-test-credentials.txt`

قوانین فایروال خودکار تغییر نمی‌کنند؛ برای دسترسی از بیرون، TCP پورت 6101 را فقط برای IP مورد اعتماد باز کن.

## به‌روزرسانی نمونهٔ آزمایشی موجود

برای دریافت آخرین اصلاحات برنامه بدون دست‌زدن به تنظیمات، توکن بله یا دیتابیس نمونهٔ آزمایشی، از اسکریپت به‌روزرسانی مخصوص همین نمونه استفاده کن:

```bash
curl -fsSL https://raw.githubusercontent.com/hatinati2/V2rayWatch/feature/bale-notifications-test/Server/scripts/update-bale-test.sh | sudo bash
```

این اسکریپت فقط برنامهٔ `/opt/v2raywatch-bale-test` را جایگزین می‌کند، سرویس آزمایشی را متوقف و دوباره اجرا می‌کند و در صورت ناموفق‌بودن بررسی سلامت، نسخهٔ قبلی برنامهٔ آزمایشی را برمی‌گرداند. فایل‌های تنظیمات، کلید رمزنگاری و دیتابیس آزمایشی حفظ می‌شوند؛ سرویس پایدار تغییری نمی‌کند.

## ۳. تنظیم ربات در پنل تست

1. آدرس آزمایشی چاپ‌شده در ترمینال را باز کن و وارد پنل شو.
2. کارت «اعلان با بله» را پیدا کن.
3. توکن ربات را وارد کن و «ذخیره تنظیمات بله» را بزن؛ تا وقتی Chat ID پیدا نشده، اعلان را خاموش نگه دار.
4. در بله به ربات پیام `/start` فرستاده باش.
5. در پنل «تشخیص Chat ID» را بزن. پنل آخرین به‌روزرسانیِ گفت‌وگوی خصوصی را می‌خواند و شناسه را پیدا و ذخیره می‌کند.
6. گزینهٔ «فعال‌سازی اعلان بله» را روشن کن؛ وضعیت این کلید بلافاصله و خودکار ذخیره می‌شود و دیگر نیاز به زدن دکمهٔ ذخیره نیست.
7. «ارسال پیام آزمایشی» را بزن و دریافت پیام را در بله بررسی کن.

اگر شناسه پیدا نشد، مطمئن شو `/start` را در گفت‌وگوی خصوصی همین ربات فرستاده‌ای و ربات webhook فعال یا مصرف‌کنندهٔ دیگری برای `getUpdates` ندارد.

## ۴. آزمایش قطع و بازیابی کانفیگ

برای تست واقعی تغییر وضعیت، بهتر است در **نمونهٔ آزمایشی** یک پروفایل موقت و جداگانه اضافه کنی. پایش را فقط در پنل تست روشن کن. پس از عبور از تعداد شکست متوالی تعیین‌شده، باید اعلان قطع به بله برسد؛ با بازیابی همان پروفایل نیز اعلان بازیابی ارسال می‌شود.

برای تست اولیه نیازی به دست‌کاری پروفایل‌ها یا تنظیمات نمونهٔ پایدار نیست. دکمهٔ «ارسال پیام آزمایشی» به‌تنهایی ارتباط خروجی از VPS تا API بله را بررسی می‌کند.

## ۵. مشاهدهٔ وضعیت و حذف نمونهٔ آزمایشی

وضعیت سرویس و لاگ‌ها:

```bash
sudo systemctl status v2raywatch-bale-test
sudo journalctl -u v2raywatch-bale-test -n 100 --no-pager
```

برای حذف نمونهٔ آزمایشی، ابتدا سرویس جداگانه را متوقف کن و سپس فقط مسیرهای مخصوص تست را حذف کن:

```bash
sudo systemctl disable --now v2raywatch-bale-test
sudo rm -f /etc/systemd/system/v2raywatch-bale-test.service
sudo systemctl daemon-reload
sudo rm -rf /opt/v2raywatch-bale-test /etc/v2raywatch-bale-test /var/lib/v2raywatch-bale-test
sudo rm -f /root/v2raywatch-bale-test-credentials.txt
```

این دستورات مسیرهای نسخهٔ پایدار را حذف یا تغییر نمی‌دهند.

## امنیت

- توکن ربات در دیتابیس آزمایشی با `/etc/v2raywatch-bale-test/profile.key` رمز می‌شود.
- کلید رمزنگاری و اطلاعات ورود نمونهٔ تست با نمونهٔ پایدار مشترک نیستند.
- پنل فعلی HTTP است؛ توکن را فقط از شبکهٔ مورد اعتماد وارد کن.
- درخواست‌های خروجی به API بله از HTTPS به `https://tapi.bale.ai` ارسال می‌شوند.
- نسخهٔ پایدار، تگ `v0.3.2` و Release رسمی با این آزمایش تغییر نمی‌کنند.

## قالب پیام اعلان

پیام خودکار قطع و بازیابی، و همچنین پیام دکمهٔ آزمایشی، فقط از قالب زیر استفاده می‌کند و نام پروفایل، میزبان، پورت، پروتکل یا زمان را در متن پیام نمی‌فرستد:

- قطع شدن پروفایل اول: `no 1 red`
- وصل شدن دوبارهٔ پروفایل اول: `no 1 green`

شماره مطابق ترتیب فعلی پروفایل‌ها در فهرست پنل است (همان ترتیب نمایش پنل). با افزودن، حذف یا تغییر نام پروفایل‌ها ممکن است شمارهٔ ردیف بعضی موارد تغییر کند؛ بنابراین شماره را با ترتیب فعلی فهرست تطبیق بده.
