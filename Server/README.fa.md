# V2rayWatch Server

نسخهٔ مستقل Linux با پنل وب، با رابط نزدیک به نسخهٔ Windows و سرویس پایش systemd. این نسخه هنوز preview است و جایگزین نسخه‌های Android و Windows نیست.

## آماده در این مرحله
- ASP.NET Core روی .NET 10 با ساختار Core / Engine / Web
- PATH اختصاصی از اولین نصب و پشتیبانی تمام endpointها زیر prefix
- پورت پیش‌فرض **6100** (برای سازگاری با محدودیت پورت Firefox؛ 6000 توسط مرورگر مسدود می‌شود) و قابل تغییر
- ورود مدیر با رمز تصادفی نصب، کوکی HttpOnly و محدودیت تلاش ورود
- systemd و اجرای خودکار پس از reboot با کاربر غیر root
- پایش پس‌زمینه با ذخیرهٔ وضعیت فعال، ادامه پس از reboot، ثبت ۵۰ نتیجهٔ اخیر و تاریخچهٔ ۲۴ ساعت/۷ روز
- مدیریت Subscription مبتنی بر HTTPS: افزودن، به‌روزرسانی تکی/گروهی و حذف همراه پروفایل‌های متعلق به آن
- تنظیمات فاصلهٔ پایش، تعداد شکست، timeout و URLهای تست؛ ذخیره در SQLite
- رابط فارسی/انگلیسی، تم روشن/تیره، جست‌وجوی پروفایل، تست تکی/گروهی و آمار خلاصه
- اعلان Gmail هنگام قطع و بازیابی خودکار کانفیگ؛ امکان ارسال مستقیم یا عبور SMTP از یک پروفایل خروجی Xray
- اسکریپت Native مخصوص Ubuntu 24.04 و Ubuntu 26.04

**محدودیت‌های باقی‌مانده:** نمایش و ذخیرهٔ QR پروفایل و پشتیبان رمزگذاری‌شدهٔ مشترک Windows/Android پیاده‌سازی شده‌اند؛ اسکن تصویر QR در Linux و اعلان مرورگر هنگام بسته بودن داشبورد هنوز وجود ندارند. اعلان Gmail از سرویس مانیتورینگ پس‌زمینه ارسال می‌شود و به بازبودن پنل وابسته نیست. پشتیبان مشترک، URLهای Subscription را شامل نمی‌شود و پایش پس از بازیابی خودکار فعال نمی‌شود. سقف پروفایل ۱۰۰ عدد است.

## نصب با یک دستور
روی سرور تازه Ubuntu 24.04 یا 26.04 فقط این دستور را اجرا کن:
```bash
curl -fsSL https://raw.githubusercontent.com/hatinati2/V2rayWatch/feature/linux-server/Server/scripts/bootstrap-install.sh | sudo bash
```
پورت پیش‌فرض 6100 است. برای تغییر پورت، مثلاً:
```bash
curl -fsSL https://raw.githubusercontent.com/hatinati2/V2rayWatch/feature/linux-server/Server/scripts/bootstrap-install.sh | sudo bash -s -- --port 6200
```
این دستور فضای موقت را روی `/var/tmp` قرار می‌دهد، .NET 10 را نصب یا نسخهٔ موجود را دوباره استفاده می‌کند، سورس همین شاخه را build می‌کند و سپس Xray Core و سرویس systemd را نصب می‌کند. پورت پیش‌فرض ۶۱۰۰ است تا با محدودیت مرورگر روی پورت ۶۰۰۰ برخورد نکند. نصب‌کننده اگر نصب قبلی را تشخیص دهد، برای جلوگیری از بازنویسی داده‌ها متوقف می‌شود. اگر مخازن قدیمی focal/jammy روی سیستم باشند، فقط هشدار می‌دهد و آن‌ها را خودکار تغییر نمی‌دهد.

### به‌روزرسانی نصب موجود (بدون حذف اطلاعات)

برای نسخه‌ای که قبلاً نصب شده، **bootstrap را دوباره اجرا نکن**؛ از updater استفاده کن:
```bash
curl -fsSL https://raw.githubusercontent.com/hatinati2/V2rayWatch/feature/linux-server/Server/scripts/update-ubuntu.sh | bash
```
Updater برنامه را در مسیر موقت روی دیسک build می‌کند، قبل از تعویض سرویس از نسخهٔ فعلی snapshot می‌گیرد و اگر نسخهٔ جدید بالا نیاید، فایل‌های برنامه و unit قبلی systemd را برمی‌گرداند. فایل تنظیمات، رمز مدیر، PATH پنل، کلید رمزنگاری و بانک اطلاعاتی در مسیرهای مستقل باقی می‌مانند.

## ساخت و نصب دستی
روی سیستم build، .NET 10 SDK نصب باشد:
```bash
bash Server/scripts/publish-linux.sh
```
پوشهٔ `Server/publish` را به Ubuntu 24.04 یا Ubuntu 26.04 منتقل کنید. نصب‌کننده وابستگی‌ها، ASP.NET Core Runtime نسخه 10 و Xray Core رسمی متناسب با x86_64 یا ARM64 را نصب می‌کند و SHA-256 بسته Xray را اعتبارسنجی می‌کند:
```bash
sudo bash Server/scripts/install-ubuntu.sh
```
پورت قابل تغییر است:
```bash
sudo bash Server/scripts/install-ubuntu.sh --port 6200
```
PATH تصادفی تولید می‌شود. PATH دلخواه:
```bash
sudo bash Server/scripts/install-ubuntu.sh --port 6100 --path /vw-my-private-panel-path
```
PATH باید با / شروع شود و 16 تا 64 نویسهٔ امن داشته باشد. ریشهٔ / پنل را نمایش نمی‌دهد.

آدرس نمونه: `http://SERVER-IP:6100/vw-<random-token>`
نام کاربری `admin` است. رمز اولیه در خروجی و فایل `/root/v2raywatch-initial-credentials.txt` با مجوز 0600 ذخیره می‌شود؛ آن را امن نگه دارید و فایل را حذف کنید.

تنظیمات پنل در `/etc/v2raywatch/server.json` و تنظیمات پایش/اشتراک‌ها/تاریخچه در SQLite ذخیره می‌شوند. پس از تغییر پورت یا PATH:
```bash
sudo systemctl restart v2raywatch
sudo systemctl status v2raywatch
sudo journalctl -u v2raywatch -n 100 --no-pager
```

## رمزنگاری داده پروفایل
اطلاعات خام لینک و تنظیمات شامل رمزها داخل SQLite با AES-256-GCM رمز می‌شوند. کلید در `/etc/v2raywatch/profile.key` قرار دارد؛ حتماً از آن نسخهٔ پشتیبان امن بگیر. بدون این کلید پروفایل‌های ذخیره‌شده قابل بازیابی نیستند. فایل پشتیبان مشترک با عبارت عبور مستقل AES-256-GCM و PBKDF2 رمز می‌شود؛ عبارت عبور را جداگانه نگه دار.

## اعلان Gmail
در تنظیمات پنل، بخش «اعلان با Gmail» را باز کن. آدرس حساب فرستنده، آدرس دریافت‌کننده و App Password گوگل را وارد کن. برای Gmail باید تأیید دومرحله‌ای حساب فعال باشد و App Password مخصوص برنامه بسازی؛ رمز اصلی حساب گوگل را وارد نکن. پس از ذخیره، «ارسال ایمیل آزمایشی» را بزن.

اگر سرور ایران مستقیماً به Gmail دسترسی ندارد، از مسیر اتصال، یکی از پروفایل‌های خارجی ذخیره‌شده در V2rayWatch را انتخاب کن. برنامه هنگام ارسال، Xray را با یک SOCKS موقت فقط روی 127.0.0.1 اجرا می‌کند و پس از پایان می‌بندد؛ پورت عمومی جدیدی باز نمی‌شود و پورت‌های تونل کاربران تغییر نمی‌کنند. ارتباط SMTP با Gmail از STARTTLS روی پورت خروجی 587 استفاده می‌کند.

App Password در SQLite با کلید AES-256-GCM برنامه رمزنگاری می‌شود و در API به مرورگر برگردانده نمی‌شود. بااین‌حال پنل HTTP است؛ رمز هنگام ثبت از مرورگر تا سرور در مسیر شبکه رمزنگاری نمی‌شود. تنظیم Gmail را فقط از شبکه یا IP مورد اعتماد انجام بده. تنظیمات و رمز Gmail داخل فایل پشتیبان مشترک Windows/Android قرار نمی‌گیرند.

## امنیت
پنل فعلاً فقط HTTP است؛ PATH تصادفی جایگزین احراز هویت نیست و HTTP رمز عبور/کوکی نشست را در مسیر شبکه رمزنگاری نمی‌کند. برای تست Public پورت را در Firewall فقط برای IPهای مورد اعتماد باز کنید. نصب‌کننده Firewall را تغییر نمی‌دهد.

برنامه: `/opt/v2raywatch` · تنظیمات: `/etc/v2raywatch` · داده‌ها: `/var/lib/v2raywatch` · سرویس: `v2raywatch`
